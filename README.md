# SQL Data Analytics Practice

This repository contains my SQL practice and problem-solving journey as I build and strengthen my skills for Data Analyst roles.

It includes SQL problems from platforms such as **LeetCode** and **HackerRank**, covering concepts from basic queries to advanced SQL techniques.

## Topics Covered

- Filtering and Sorting
- Aggregations and `GROUP BY`
- Joins
- Subqueries and CTEs
- `CASE` Statements
- Window Functions
- Date and Time Functions
- Ranking and Analytical Functions
- Moving Averages and Running Totals
