# 🎵 Spotify Music Analysis

## 📌 Project Overview

This project analyzes Spotify track data to identify factors associated with **music popularity and audience engagement**.

The project uses **PostgreSQL and SQL** for data cleaning, validation, and analysis, and **Power BI** to create an interactive dashboard for visualizing key insights.

---

## 🎯 Project Objectives

* Analyze factors influencing track popularity
* Explore relationships between audio features and popularity
* Perform data cleaning and validation
* Identify patterns across different music genres
* Present key findings through an interactive Power BI dashboard

## 🧹 Data Cleaning & Validation

The dataset was examined for data-quality issues before performing the analysis.

### Key Steps

* Identified missing values
* Checked for duplicate records
* Validated numerical values and expected ranges
* Checked for empty strings and unnecessary spaces
* Validated categorical and numerical fields
* Removed duplicate records where appropriate
